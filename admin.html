UniLondon listings editor

Only you need this page. Students never see it. Events aren't edited here: they update automatically twice a day from the official UCL union, LSE union, King's and LSE calendars (see events.json). Use this page for everything else: food, study spaces, deals, funding, jobs, sport and housing, plus any event you want to add by hand.

How to update the live app
  1. Open a listing on the left, check it against its official page, fix anything, then press Mark checked.
  2. Add new ones with New listing. Your edits are kept in this browser until you download.
  3. Press Download listings.json, then upload that file to your GitHub repository, replacing the old one. The app updates within a minute or two.

Pick a listing to edit it.
