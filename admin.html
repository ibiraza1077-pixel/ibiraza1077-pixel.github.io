UniLondon listings editor

Only you need this page. Students never see it. Events aren't edited here: they update automatically twice a day from the official UCL union, LSE union, King's and LSE calendars (see events.json). Use this page for everything else: food, study spaces, deals, funding, jobs, sport and housing, plus any event you want to add by hand.

Sync

Open on GitHub

Runs automatically at about 06:15 and 16:15 every day. Sync now runs it immediately: it pulls new events from the official calendars and re-checks every listing against its official page. It takes about 2 minutes, and the live app updates a minute after that.

Connect this page to GitHub (one-time, needed for Sync now and Publish)
  1. Open GitHub → New fine-grained token.
  2. Name it "UniLondon admin", set an expiry, and under Repository access choose Only select repositories → .
  3. Under Repository permissions set Actions: Read and write and Contents: Read and write. Nothing else.
  4. Generate it, copy it, and paste it below. It's saved only in this browser on this device, and it can only touch this one repository.
Editing listings
  1. Open a listing on the left, check it against its official page, fix anything, then press Mark checked today.
  2. Add new ones with New listing. Your edits are kept in this browser until you publish.
  3. Press Publish to site. With the page connected to GitHub, your edits go live within a minute or two. (Not connected? Use Download listings.json and upload it to GitHub instead.)
